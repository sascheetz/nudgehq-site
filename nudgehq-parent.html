Bookmark Automation

Open both Canvas JSON URLs at once with a single click using a JavaScript bookmarklet. Takes 2 minutes to set up.

1
Create a new bookmark in Chrome

Right-click the bookmarks bar → Add page (or press ⌘ + D anywhere).

2
Name it "Get Canvas Data"

In the Name field type: Get Canvas Data

3
Paste this as the URL

Delete whatever is in the URL field and paste this entire block:

javascript:(function(){window.open('https://lakota.instructure.com/api/v1/users/self/upcoming_events?per_page=50','_blank');setTimeout(function(){window.open('https://lakota.instructure.com/api/v1/users/self/missing_submissions?filter[]=submittable&per_page=50','_blank');},500);})();
4
Click Save

The bookmark now appears in your bookmarks bar.

5
How to use it daily

While logged into Canvas in Chrome:

  1. Click the Get Canvas Data bookmark
  2. Two tabs open — each showing JSON data
  3. In each tab press ⌘ + S to save
  4. Save as upcoming.json and missing.json
  5. Come back to the dashboard and load the files
💡 Tip: Keep a folder on your Desktop called "Canvas Data" and always save the files there. That way they're easy to find when you load them into the dashboard.

Twilio SMS Setup

One-time setup, ~10 minutes. A local phone number costs ~$1.15/month — no business registration required.

1
Create a free Twilio account

twilio.com/try-twilio — no credit card needed for the trial.

2
Get a local phone number (~$1.15/mo)

Console → Phone Numbers → Manage → Buy a Number. Filter by SMS. Choose a local 10-digit number — do NOT choose a toll-free 800 number as those require business registration. A local number works immediately with no extra paperwork.

3
Verify his number (trial only)

During the free trial, Twilio can only text numbers you've verified. Go to Phone Numbers → Verified Caller IDs → add his number. He'll get a one-time confirmation code. Once you add the $1.15/mo local number this step is no longer needed.

4
Copy Account SID and Auth Token

Both on your Twilio Console homepage.

SID: ACxxxxxxxxxxxxxxxxxxxx
🔒 Credentials stay in your browser only — sent directly to Twilio when you tap a nudge button.

Make.com Auto-Reminder

Sends automatic morning texts from real Canvas API data. Free Make.com account, ~20 min setup.

1
Schedule Trigger

Make.com → New Scenario → Schedule → Every Day at your chosen time.

2
HTTP: Fetch missing submissions
URL: https://lakota.instructure.com/api/v1/users/STUDENT_ID/missing_submissions
Method: GET
Headers:
  Authorization: Bearer YOUR_OBSERVER_TOKEN
Query: filter[]=submittable
3
Iterator → loop each missing item

Flow Control → Iterator on the response array.

4
Check if he already marked it done

Check the student dashboard to see if he checked it off. If result is true, skip with a Filter.

5
Twilio: Send SMS

Connect Twilio → Send an SMS. Use message template below.

Message template:
Hey! Just checking in 💙 It looks like "{{name}}" hasn't been submitted in Canvas yet. No stress — you've totally got this. We're here if you need help! ❤️
✅ Step 4 means if he's already checked it off on his device, Make.com will skip texting about it. His check-offs actually reduce your noise.

Getting Canvas JSON Files

While logged into Canvas, you can download your assignment data as JSON files. No API token needed — your browser session handles authentication.

1
Log into Canvas

Go to lakota.instructure.com and log in with his student account.

2
Get upcoming assignments

Paste this URL into the address bar and press Enter:

https://lakota.instructure.com/api/v1/users/self/upcoming_events?per_page=50

You'll see raw JSON in the browser. Press ⌘ + S and save as upcoming.json

3
Get missing assignments

Paste this URL into the address bar:

https://lakota.instructure.com/api/v1/users/self/missing_submissions?filter[]=submittable&per_page=50

Press ⌘ + S and save as missing.json

4
Load into the dashboard

Come back here, click the file pickers above, select your saved files, and click Load from Files.

✅ Do this once a day (morning works well) to keep the dashboard current. No token or proxy needed.
★
Automate with a bookmark

You can open both URLs at once with a single browser bookmark. See the automation guide below.

Google Sheets Setup

One-time setup, ~5 minutes. Assignments will be appended to your sheet on every export.

1
Create a Google Sheet

Go to sheets.google.com and create a new spreadsheet. Name it "Nudge HQ Assignments".

2
Open Apps Script

In your sheet: Extensions → Apps Script. Delete any existing code.

3
Paste the script

Download the NudgeHQ_AppScript.js file and paste its contents into the Apps Script editor. Click Save.

4
Deploy as web app

Click Deploy → New deployment. Set type to Web app. Set "Who has access" to Anyone. Click Deploy and authorize when prompted.

5
Copy the web app URL

Copy the URL that looks like https://script.google.com/macros/s/…/exec and paste it into the Apps Script URL field in ⚙ Settings.

✅ Done! Click "Export to Sheets" anytime to append current assignments to your sheet.
