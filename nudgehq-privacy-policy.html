Nudge HQ — Privacy Policy

Last updated: September 25, 2026

Nudge HQ ("the Extension") is a Chrome extension designed to help parents monitor their child's Canvas LMS assignment data. This policy explains what data is collected, how it is used, and how it is stored.

1. Data Collected

The Extension collects the following data when you use it on your child's Canvas LMS account:

  • Student name and Canvas user ID
  • Course names and IDs
  • Assignment names, due dates, submission status, and scores
  • Missing assignment information
  • Submission types

The Extension also reads data from Home Access Center (HAC) when the user activates the Capture feature, including assignment names, scores, and grade percentages.

2. How Data Is Used

All collected data is used solely to display assignment information in the Nudge HQ parent dashboard. The data is used to:

  • Show upcoming, missing, and completed assignments
  • Display at-a-glance stats for parents
  • Enable cross-device access via cloud sync
  • Send SMS reminders to parents via Twilio (only when manually triggered by the user)

3. Data Storage

Data is stored in two locations:

  • Locally: In Chrome's local extension storage (chrome.storage.local) on the user's device
  • Cloud: On Supabase (supabase.co), a third-party database service, when the user enables cloud sync. Data is stored per student ID and is only accessible by the account holder.

4. Data Sharing

Data is shared with the following third parties solely to provide the Extension's functionality:

  • Supabase (supabase.co): Cloud database storage for cross-device sync
  • Twilio: SMS delivery when the user manually triggers a reminder. Only the student's name and assignment information are included in SMS messages.

We do not sell, rent, or share user data with any other third parties. Data is never used for advertising or marketing purposes.

5. Data Retention

Data stored in Supabase is retained until the user deletes it or stops using the Extension. Local Chrome storage data is cleared when the Extension is uninstalled.

6. User Control

Users can clear all stored data at any time by uninstalling the Extension, which removes all local storage data. Cloud data can be deleted by contacting the developer.

7. Children's Privacy

The Extension is designed for use by parents to monitor their own child's academic data. All data collected belongs to the parent/guardian who installed the Extension and is used solely for that purpose.

8. Contact

For questions about this privacy policy or to request data deletion, please contact the developer through the Chrome Web Store listing.
